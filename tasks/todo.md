# Tasks

Branch-local task notes. Add a `# Task:` section for the current branch's work,
and before opening its PR resolve every unchecked item or promote it to a
GitHub issue. Once a section is done or tracked, delete it: the plan, ADR,
issue and PR keep the durable record.
